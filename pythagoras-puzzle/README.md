# 피타고라스 퍼즐 챌린지 (10라운드 · 라운드별 TOP 5)

두 직각변 위의 정사각형 조각을 **끌고 · 돌려서** 빗변 위의 정사각형을 채우는 교실용 스피드 퍼즐입니다.
교사가 전자칠판에 QR을 띄우면 학생이 태블릿으로 찍어 입장하고, 교사가 **게임 시작**을 누르면 모두 동시에 출발합니다.

## 바로 써 보기
`dist/` 폴더가 이미 빌드되어 있습니다. 아무 정적 호스팅에 올리면 끝입니다. 설치할 것은 없습니다.

| 주소 | 화면 |
|---|---|
| `/` | 첫 화면 (10단계 미리보기) |
| `/?teacher` | 교사 화면: QR · 방 번호 · 게임 시작 · 실시간 순위판 |
| `/?room=1234` | 학생 입장 (QR이 이 주소로 연결됨) |
| `/?play` | 혼자 연습하기 (서버 없이 동작, 개인 최고 기록 저장) |

## Firebase에 올리기 (무료 Spark 요금제)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다.
2. **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 `asia-southeast1` 추천, *잠금 모드*로 시작).
3. 데이터 탭 맨 위의 주소(예: `https://my-class-default-rtdb.asia-southeast1.firebasedatabase.app`)를 복사해
   `dist/config.js`의 `firebaseDatabaseURL`에 붙여 넣습니다. (`public/config.js`도 같이 바꿔 두면 다시 빌드해도 유지됩니다.)
4. `.firebaserc`의 `YOUR-FIREBASE-PROJECT-ID`를 내 프로젝트 ID로 바꿉니다.
5. 터미널에서:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase deploy        # 호스팅 + 데이터베이스 보안 규칙 함께 배포
   ```
6. `https://<프로젝트ID>.web.app/?teacher` 를 전자칠판에서 엽니다.

> `config.js`를 비워 두면 순위판 없이 각자 기록을 재는 ‘혼자 하기’ 모드로 동작합니다.

## 수업 흐름
1. 교사 화면(`/?teacher`)을 열면 QR과 4자리 방 번호가 나옵니다.
2. 학생이 QR을 찍으면 **10개 라운드 선택 화면**이 나옵니다. 원하는 라운드를 눌러 아무 때나 도전합니다.
3. 라운드마다 시간을 **따로** 잽니다 (3·2·1 후 시작, 정답을 맞히면 시간 정지).
4. 기록이 그 라운드의 **TOP 5 안**에 들면 닉네임 입력칸이 나오고, 저장하면 교사 화면 순위판에 바로 올라갑니다.
   TOP 5 밖이면 5위까지 몇 초 남았는지 알려 줍니다.
5. 교사 화면: 라운드별 TOP 5 카드 10개(새 기록이 올라오면 노랗게 반짝임) + **10라운드 완주 순위**(각 라운드 개인 최고 기록의 합).
6. **기록 초기화**(두 번 눌러 확인)로 방의 모든 기록을 지우거나, **새 방 만들기**로 반을 바꿀 수 있습니다.

- 한 태블릿은 라운드마다 TOP 5에 한 줄만 차지하고, 더 좋은 기록이 나오면 그 줄이 갱신됩니다.
- Firebase 주소가 없으면(또는 `/?play`) 기록이 **그 기기에만** 저장되는 TOP 5로 동작합니다. 한 태블릿을 여러 학생이 돌려 쓸 때 좋습니다.

## 조작법
- **끌기**: 조각을 손가락으로 끌어 옮기기
- **회전**: 조각을 누르면 생기는 파란 손잡이를 돌리기 / 두 손가락으로 돌리기 / 아래 ↺ ↻ 버튼(의미 있는 각도로 한 번에 회전)
- **자석**: 조각을 내려놓을 때 근처(약 6% 거리, 8° 이내)의 변이 있으면 평행하게 돌아가며 딱 붙고, 가까운 꼭짓점끼리도 맞춰집니다.
- **맞추기**: 알맞은 자리·방향 근처에 놓으면 ‘착’ 붙고 고정됩니다. 틀린 자리면 조각이 흔들립니다.
- **라운드 클리어**: 시간이 멈추고 이번 기록(초)과 그 라운드의 TOP 5가 표시됩니다. 다시 도전 / 라운드 선택 / 다음 라운드 중에서 고릅니다.
- **힌트 (+10초)**: 고른 조각이 들어갈 자리를 깜빡여 보여 줍니다.
- **조각 제자리**: 아직 붙지 않은 조각을 처음 위치로 되돌립니다.

## 10단계 구성
| 단계 | 증명 | 조각 수 | 회전 |
|---|---|---|---|
| 1 | 격자 세기 (3-4-5) | 25 | 필요 |
| 2 | 페리갈의 분할 | 5 | 불필요 (평행이동만) |
| 3 | 직각이등변삼각형 ① (정사각형 + 삼각형 8개) | 9 | 일부 |
| 4 | 신부의 의자 (타비트 이븐 쿠라) | 5 | 필요 |
| 5 | 직각이등변삼각형 ② (반쪽 + 4분의 1) | 6 | 일부 |
| 6–8 | 평면 채우기(테셀레이션) 분할 | 6–7 | 일부 단계 90° |
| 9 | 바스카라의 바람개비 (삼각형 4개 + 가운데 정사각형) | 7 | 필요 |
| 10 | 평면 채우기 ④ | 8 | 필요 |

모든 퍼즐의 좌표는 `tools/gen_levels.py`가 계산해서 **각 정사각형이 빈틈없이 정확히 채워지는지, 모든 조각이 뒤집지 않고 회전·이동만으로 옮겨지는지** 자동으로 검증합니다.
같은 모양의 조각은 서로 바꿔 놓아도 정답으로 인정됩니다.

## 개발
```bash
npm install            # esbuild, typescript
npm run typecheck      # tsc --noEmit
npm run build          # src → dist (app.js ≈ 50KB, app.css ≈ 12KB)
npm run levels         # (python3) 퍼즐 좌표 다시 생성·검증
node tools/mock-firebase.mjs 9000   # 오프라인 테스트용 가짜 Firebase (config.js에 http://localhost:9000)
```
- `src/puzzle.ts` 드래그·회전·스냅 엔진 (SVG, Pointer Events, 멀티터치)
- `src/qr.ts` 외부 라이브러리 없는 QR 생성기 (학교 방화벽에서도 동작)
- `src/net.ts` Firebase Realtime Database REST/SSE 클라이언트 (SDK 없음)
- `database.rules.json` 방(rooms) 경로만 읽기/쓰기를 허용하는 보안 규칙

※ 학생 로그인이 없는 대신 방 경로는 누구나 쓸 수 있습니다. 수업이 끝나면 Firebase 콘솔에서 `rooms` 데이터를 지워도 됩니다.
